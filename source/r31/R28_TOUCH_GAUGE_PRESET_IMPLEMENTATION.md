# r28 touch, gauge and preset corrections

## Tables
Single-touch long-press selection and two-touch pinch zoom have separate state. A second touch cancels and restores any pending/active range selection before zooming. Long-press then drag works; long-press and release retains the first-corner workflow.

## Dashboard gauges
Gauge scale labels are generated from major tick spacing rather than being reduced to only minimum/midpoint/maximum. Long-press opens a per-gauge local display-limit editor. Gauge text, context menus and drag selection are suppressed.

## Logging presets
Three custom presets are rendered as the same opaque three-column button row as the defaults. Tap loads; long-press opens a modal editor for the name and up to eight stored channels.
